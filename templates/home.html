How it works

A hyperlink pairs a readable name with a web address. Your reader sees the name and clicks it to open the original page.

  1. Name your link. Choose text that explains the destination, such as “Python functions guide.”
  2. Add the address. Paste the full HTTP or HTTPS URL, then select Create hyperlink.
  3. Copy and paste. Select Copy hyperlink and paste normally into an editor that supports formatted text.

The destination stays the same. The tool changes the displayed text; it does not shorten the URL, change access permissions, or save your links.

Paste tips for each app
  • Microsoft Teams

    Use the formatted composer in chats or channels. If the pasted label is lost, use Format → Insert link to set the display text.

  • Zoom Chat

    Use the rich-text composer and its Link option. In-meeting chat may behave differently, and your organization can restrict hyperlinks.

  • Gmail

    Paste into the email body with plain text mode turned off.

  • Microsoft Outlook

    Use an HTML message body and keep formatting when pasting.

  • Microsoft Word

    Paste into a document. Keep Source Formatting preserves the copied formatting.

  • Google Docs

    Paste into the document body. You can edit the link text and destination afterward.

  • Notion

    Use a page’s text blocks. The page title and other plain text fields may handle links differently.

Keep the name when you paste

Use a normal paste, rather than Paste as plain text. In editors with paste options, choose Keep Source Formatting or HTML when available. Once pasted, use the destination app’s text tools to style the link.

If only the address appears, your browser or destination may have removed the formatting. You can still select text in that app, choose Insert link, and add the original address.

Plain text editors, address bars, and fields that only accept text will not retain a named, clickable hyperlink. Private files still require the recipient to have permission to open them.
